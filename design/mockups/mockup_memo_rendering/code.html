ARTIFACT를 등록하는 과정의 이분화 문제

문제 확인 필요

아티팩트(ARTIFACT) 생성이 작업 런타임 내 분산되어 있어, 컨텍스트 추론 실패 시 누락될 가능성이 존재합니다. 아래 두 가지 등록 경로의 일관성 보완이 요구됩니다.

1 Codex 작업 세션 도중 아티팩트 등록

Codex는 아티팩트를 등록하는 record_artifact() 도구의 설명을 보고, 해당 도구가 WI의 아티팩트로 등록되어야 할 가치가 있다고 판단하면 해당 도구를 호출하여 저장한다.

단, 현재 구조상 AGENTS.md나 PostToolUse Hook에 명시된 내용은 아니므로 반드시 작동하지는 않고, 확률적으로 추론하여 작동된다.

2 $work-finish 에서의 등록 중요

$work-finish 스킬에서는 해당 턴의 컨텍스트를 읽고 WI에 등록되지 않았으나 가치가 있는 아티팩트 후보를 직접 찾아서 가치를 검증하고 직접 등록한다.

이는 $work-finish의 파이프라인 상 명시되어 있는 내용이므로 거의 반드시 실행된다.
